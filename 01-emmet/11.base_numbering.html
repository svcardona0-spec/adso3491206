11-Base Numbering (Número Base de Secuencia)

Objetivo: Aprender a cambiar el número desde el cual comienza la secuencia de numeración añadiendo el modificador @N (donde N es el número inicial deseado) después del signo de dólar en Emmet.

Ejemplo práctico con Emmet

Si escribes la siguiente abreviatura en tu editor (indicando que empiece a contar desde el número 5) y presionas Tab:

ul>li.item-$@5*3

Emmet generará automáticamente elementos cuyas clases comienzan a numerarse a partir del 5:

<ul>
    <li class="item-5"></li>
    <li class="item-6"></li>
    <li class="item-7"></li>
</ul>
