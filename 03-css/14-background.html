14-background

Control background colors, images, positioning, repetition, and sizing for elements.

Propiedades de Fondo (Background)

Las propiedades de fondo permiten estilizar el área visual detrás del contenido de un elemento:

Caja de Demostración

Esta caja combina color, imagen degradada, posición y escala.

  • background-color: Establece el color de fondo sólido.
  • background-image: Define una o varias imágenes de fondo (o degradados).
  • background-repeat: Controla si la imagen se repite en mosaico (repeat, no-repeat, repeat-x, repeat-y).
  • background-position: Define la ubicación inicial de la imagen de fondo (ej. center, top left).
  • background-size: Ajusta el tamaño de la imagen (ej. cover, contain, o medidas específicas).
