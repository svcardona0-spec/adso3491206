Sistema de Cuadrícula Bidimensional (CSS Grid Layout).

CSS Grid Layout

Sistema de diseño bidimensional enfocado en filas y columnas que permite estructurar layouts web complejos y organizados con gran precisión.

  • display: grid;: Define un contenedor de cuadrícula para estructurar elementos en filas y columnas simultáneamente.
  • grid-template-columns / rows: Establece el tamaño y número de pistas (columnas y filas) usando medidas fijas, porcentajes o fracciones (fr).
  • gap: Controla de forma limpia y uniforme el espacio de separación entre celdas o elementos de la cuadrícula.
  • grid-column / grid-row: Permiten que un elemento específico abarque múltiples celdas dentro del layout.
