Use fonts that are not installed on the user's computer.

Fuentes Web (Web Fonts & Google Fonts)

Permiten cargar tipografías externas alojadas en la nube para asegurar que el diseño se vea idéntico en cualquier dispositivo, sin depender de las fuentes instaladas localmente.

Poppins: Tipografía moderna y versátil para interfaces web limpias.
Dancing Script: Estilo manuscrito elegante y fluido.
PRESS START 2P: Estilo pixelado retro de videojuegos.
  • @font-face: Regla CSS nativa para importar archivos de fuentes personalizados (.woff, .woff2) alojados en tu servidor.
  • Google Fonts: Servicio externo que facilita la importación de miles de fuentes mediante enlaces en el HTML o directivas @import.
  • font-family: 'Nombre', respaldo; Propiedad para aplicar la tipografía declarando siempre una familia genérica de respaldo (sans-serif, serif, monospace).
