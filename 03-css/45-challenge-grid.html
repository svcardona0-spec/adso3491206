Galería Fotográfica Asimétrica (Irregular Gallery)

Proyecto final que combina CSS Grid avanzado, control de filas/columnas dinámicas y empaquetado automático para lograr una composición tipo collage o mosaico.

Amanecer
  • grid-auto-flow: dense;: Rellena automáticamente los huecos vacíos en la cuadrícula optimizando el espacio disponible.
  • grid-column / grid-row span: Permiten crear la asimetría haciendo que elementos específicos abarquen múltiples celdas.
  • Composición Responsiva: Se adapta perfectamente a distintas pantallas manteniendo un diseño visual dinámico y atractivo.
