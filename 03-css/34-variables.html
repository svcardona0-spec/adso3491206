34-variables

The var() function is used to insert the value of a CSS variable.

Variables CSS (Custom Properties)

Permiten almacenar valores reutilizables (como colores, fuentes o medidas) en el documento para mantener un diseño consistente y fácil de actualizar.

--primary-color
--secondary-color
--dark-color / --card-bg
  • --nombre-variable: Se declaran usualmente en el selector global :root utilizando dos guiones al inicio.
  • var(--nombre-variable): Función encargada de leer e insertar el valor asignado dentro de cualquier regla CSS.
  • Valor de respaldo (Fallback): var(--color, #000) permite definir un valor alternativo por si la variable principal no está disponible.
