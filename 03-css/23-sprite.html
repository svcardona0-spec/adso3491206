An image sprite is a collection of images put into a single image.

Técnica de Image Sprites

Un sprite CSS consiste en combinar múltiples imágenes o iconos pequeños en un solo archivo maestro. Esto reduce drásticamente el número de peticiones HTTP al servidor y mejora la velocidad de carga de la página.

Icono Uno (Posición 0 0)

Se muestra la primera sección del sprite maestro.

Icono Dos (Posición desplazada -48px)

Se desplaza el fondo con background-position para revelar otra sección de la misma imagen.

  • background-image: Carga la imagen maestra que contiene todos los iconos juntos.
  • background-position: Desplaza las coordenadas (X e Y) para encuadrar únicamente el icono deseado.
  • width / height: Delimitan el tamaño exacto de la ventanilla de visualización del icono individual.
