Transiciones CSS (Transitions)

Permiten animar de forma suave los cambios de propiedades CSS (como color, tamaño o posición) cuando un elemento pasa de un estado a otro (ej. al hacer hover).

Box
transition: all 0.4s ease
Box
transition-duration: 0.8s
Box
cubic-bezier (rebote)
  • transition-property: Especifica la propiedad CSS que sufrirá la transición (o all para todas).
  • transition-duration: Define el tiempo que tarda la transición en completarse (ej. 0.4s o 400ms).
  • transition-timing-function: Controla la velocidad de aceleración (ease, linear, cubic-bezier).
  • transition-delay: Establece un tiempo de espera antes de que comience la animación del cambio.
