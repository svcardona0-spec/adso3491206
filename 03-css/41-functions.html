Funciones Matemáticas y Lógicas en CSS

Permiten realizar cálculos dinámicos de valores, definir escalas fluidas y evaluar rangos directamente en la hoja de estilos sin requerir JavaScript.

calc()
Ancho: calc(100% - 40px)
clamp()
Texto fluido adaptable
min() / max()
min(80%, 250px)
  • calc(expression): Permite sumar, restar, multiplicar o dividir unidades mixtas (ej. 100% - 50px).
  • clamp(min, preferred, max): Establece un valor flexible que se adapta al viewport pero respeta límites mínimos y máximos.
  • min() / max(): Seleccionan automáticamente el valor menor o mayor entre varios argumentos proporcionados.
  • attr() / var(): Otras funciones nativas orientadas a recuperar atributos HTML o variables personalizadas.
