06-specificity

Is score/rank that determines which style declaration is ultimately applied to an element.

¿Cómo funciona la jerarquía?

La especificidad calcula un "puntaje" basado en el tipo de selectores utilizados. El navegador siempre aplicará la regla del selector que tenga mayor puntuación.

Tipo de Selector Peso / Puntaje Aprox.
Estilos en línea (Inline styles) 1, 0, 0, 0 (El más alto)
IDs (#id) 0, 1, 0, 0
Clases, Atributos y Pseudoclases (.class, [attr]) 0, 0, 1, 0
Elementos y Pseudoelementos (p, div, ::before) 0, 0, 0, 1

Demostración Práctica

Este texto tiene reglas de etiqueta (p), de clase (.text-class) y de ID (#unique-text) apuntándole al mismo tiempo. Como el ID tiene mayor especificidad, el texto se muestra de color rojo.
