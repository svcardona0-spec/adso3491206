Control text alignment, spacing, line height, decorations, transformations, and indentation.

Propiedades de Formato y Alineación de Texto

CSS ofrece múltiples propiedades avanzadas para refinar la presentación visual del contenido escrito:

1. Align (text-align: right): Este párrafo está alineado hacia el margen derecho.

2. Line Height (line-height: 2.2): Este bloque amplía el espacio vertical entre líneas de texto para mejorar la legibilidad.

3. Decoration (text-decoration): Este texto cuenta con una línea decorativa ondulada inferior.

4. Transform (text-transform: uppercase): Este texto transforma automáticamente todas sus letras a mayúsculas.

5. Indent (text-indent: 40px): Este párrafo aplica una sangría o espacio inicial en su primera línea.

6. Spacing (letter-spacing / word-spacing): Este texto modifica la separación entre letras y palabras.

  • text-align: Define la alineación horizontal (left, right, center, justify).
  • line-height: Controla la altura de las líneas de texto.
  • text-decoration: Añade decoraciones como subrayados o tachados.
  • text-transform: Controla las mayúsculas y minúsculas (uppercase, lowercase, capitalize).
  • text-indent: Añade sangría a la primera línea de un párrafo.
  • letter-spacing / word-spacing: Ajusta el espacio entre caracteres o palabras.
