20-pseudoclasses

Is used to define a special state of an element.

Ejemplos de Pseudoclases en Acción

Las pseudoclases permiten aplicar estilos a los elementos basándose en información contextual o en el estado de interacción del usuario:

1. :hover (Pasa el cursor sobre el botón):

2. :focus (Haz clic dentro del campo de texto):

3. :nth-child(odd) (Filas alternas en listas):

  • Elemento número 1 (Impar)
  • Elemento número 2 (Par)
  • Elemento número 3 (Impar)
  • Elemento número 4 (Par)
  • :hover: Se activa cuando el usuario coloca el cursor sobre el elemento.
  • :focus: Se activa cuando un elemento recibe el foco de entrada (como un campo de formulario).
  • :nth-child(): Selecciona elementos basándose en su posición numérica entre sus hermanos.
  • :active: Se activa durante el momento en que se hace clic sobre un elemento.
