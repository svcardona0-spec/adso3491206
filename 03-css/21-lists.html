Allows you to set all the list style properties at once.

Propiedad de Listas (List Style Shorthand)

La propiedad abreviada list-style permite configurar simultáneamente el tipo de marcador, su posición y una imagen personalizada:

1. Uso de list-style (tipo, posición e imagen):

  • Primer elemento de la lista configurada.
  • Segundo elemento utilizando la propiedad abreviada.
  • Tercer elemento con diseño compacto.

2. Uso de list-style: none para listas limpias (como menús):

  • Opción de menú o tarjeta número uno.
  • Opción de menú o tarjeta número dos.
  • list-style-type: Define el marcador (disc, circle, square, decimal, none).
  • list-style-position: Ubica el marcador dentro (inside) o fuera (outside) del contenido.
  • list-style-image: Reemplaza el marcador estándar por una imagen personalizada.
  • list-style: Propiedad shorthand que agrupa las tres propiedades anteriores en una sola línea.
