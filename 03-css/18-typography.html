Propiedades Tipográficas Básicas

La tipografía en CSS permite estilizar el texto para mejorar la legibilidad y la jerarquía visual de la interfaz web:

1. Color: Este texto muestra cómo cambiar el color del texto mediante la propiedad dedicada.

2. Family: Este texto cambia su familia tipográfica a una fuente monoespaciada.

3. Size: Este texto utiliza un tamaño de fuente mayor (1.5rem).

4. Weight: Este texto utiliza un grosor o peso de fuente más pesado (negrita de 700).

  • color: Define el color del texto.
  • font-family: Establece la familia tipográfica (fuente).
  • font-size: Controla las dimensiones y escala del texto.
  • font-weight: Define el grosor del trazo de la tipografía (ej. normal, bold, 100-900).
