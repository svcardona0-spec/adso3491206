3. Combinador de Hijo Directo (>):

Este párrafo es hijo directo del contenedor y tiene un estilo exclusivo.

  • [attribute]: Selecciona elementos que tienen un atributo específico asignado.
  • :not(selector): Excluye elementos que coincidan con el selector indicado.
  • parent > child: Selecciona únicamente los elementos hijos directos de un contenedor.
  • element + element: Selecciona el elemento adyacente inmediatamente posterior.
