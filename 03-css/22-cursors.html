22-cursors

Specifies the mouse cursor to be displayed when pointing over an element.

Tipos de Cursores en CSS

La propiedad cursor permite cambiar la apariencia del puntero del ratón al pasar por encima de un elemento, mejorando la retroalimentación visual de la interfaz:

pointer
Enlace o botón
help
Ayuda disponible
not-allowed
Acción bloqueada
crosshair
Precisión / Mira
move
Elemento movible
text
Selección de texto
  • cursor: pointer; Cambia el puntero a una mano (típico para enlaces y botones interactivos).
  • cursor: not-allowed; Indica que la acción no está permitida (muestra un círculo tachado).
  • cursor: crosshair; Muestra una cruz de precisión.
  • cursor: wait; Indica que el sistema está cargando o procesando.
