32-clip-path

Property lets you clip an element to a basic shape.

Propiedad Clip Path

Permite recortar visualmente cualquier elemento HTML o imagen utilizando formas geométricas básicas como círculos, polígonos o rectángulos inset.

circle()
polygon()
inset()
  • circle(radius at x y): Recorta el elemento en forma circular desde un punto de origen.
  • polygon(x1 y1, x2 y2, ...): Define múltiples vértices mediante coordenadas porcentuales para crear triángulos, rombos o figuras personalizadas.
  • inset(top right bottom left): Recorta los bordes interiores de la caja con opcional redondeo de esquinas.
  • Uso Creativo: Ideal para máscaras de imágenes dinámicas y transiciones avanzadas en diseño web.
